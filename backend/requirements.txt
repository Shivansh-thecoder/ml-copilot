# --- MCP client (Phase A) ---
# The MCP SERVER still runs in its own isolated environment
# (backend/mcp/.venv, backend/mcp/requirements.txt) -- see
# backend/mcp/README.md section 4. This is the MCP CLIENT half, used by
# backend/langgraph/mcp_client/ to talk to that server (spawned as a

# dependency is `starlette>=0.27` (no upper bound) -- the earlier

# sse-starlette to an old version whose OWN starlette requirement is
# unconstrained (1.6.1 requires bare "starlette", no floor) resolves this
# without touching starlette at all -- verified: installing both together
# left the already-pinned starlette==0.41.3 completely untouched, `pip
# check` clean, and every LangGraph/FastAPI regression test still passing.
mcp==1.29.0
